◆ svc_sched_dispatch()

void svc_sched_dispatch ( void )

Run due tasks cooperatively.

Call this from the main while(1) loop. It runs tasks whose due time has elapsed. Tasks run to completion; there is no preemption.

◆ svc_sched_tick_isr()

void svc_sched_tick_isr ( void )

Tick ISR hook.

This function increments the tick counter and requests a dispatch in the main loop.

svc_sched_init() installs this function directly into the Cortex-M vector table (VTOR[15]) so that no SysTick_Handler symbol is emitted by the library. Applications that need to share SysTick with other uses must chain a call to this function from their own handler after restoring or managing the VTOR entry themselves.
