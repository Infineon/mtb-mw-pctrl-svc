 MacrosMacros for defining mutex states and operations
 Data StructuresData structures for mutex type definition
 FunctionsFunctions for mutex operations such as lock and unlock
 ▼ProfilingThe profiling interfaces leverages the built-in DWT (Data Watchpoint and Trace) unit in ARM Cortex-M processor cores to measure code execution time with high precision
 FunctionsFunctions for initializing the DWT, starting and stopping profiling, and reading results
 ▼PPCA WatchdogThe PPCA watchdog service provides a mechanism to monitor the activity and health of PPCA cores in a multi-core system
 MacrosMacros for configuring the PPCA watchdog, such as hardware selection and timing parameters
 Data StructuresData structures for PPCA watchdog configuration and status
 FunctionsFunctions for initializing, configuring, and servicing the PPCA watchdog
 ▼Basic SchedulerA lightweight cooperative task scheduler driven by a periodic tick (typically SysTick)
 MacrosMacros for configuring the scheduler, such as maximum tasks and tick conversion
 Data StructuresData structures for task control blocks and related types
 FunctionsFunctions for initializing the scheduler, adding tasks, and dispatching
 ▼Stack MonitorThe monitor places a guard word at the stack limit and fills the remaining stack region with STACK_FILL_WORD
 MacrosMacros for configuring the stack monitor, such as fill patterns and scan options
 FunctionsFunctions for initializing the stack monitor and updating/reading the high-water mark
