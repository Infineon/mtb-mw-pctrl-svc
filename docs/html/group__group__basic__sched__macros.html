#define SVC_SCHED_MAX_TASKS   16

Maximum number of tasks that can be registered in the scheduler.

Default 16.

◆ SVC_SCHED_MAX_PERIOD_TICKS

#define SVC_SCHED_MAX_PERIOD_TICKS   (0x7FFFFFFFu)

Maximum supported delay/period in ticks.

The scheduler uses wrap-safe time comparisons based on signed 32-bit deltas (see implementation of due checks). For that technique to be unambiguous across tick wrap, delays must be strictly less than 2^31 ticks.
