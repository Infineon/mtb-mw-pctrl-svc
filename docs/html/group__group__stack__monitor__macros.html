Stack Monitor

Macro Definition Documentation

◆ STACK_TOP

#define STACK_TOP   ((uint32_t*)&__INITIAL_SP)

Stack top address (highest address of the stack region).

Defined as the initial stack pointer value from the linker script.

◆ STACK_LIMIT

#define STACK_LIMIT   ((uint32_t*)&__STACK_LIMIT)

Stack limit address (lowest address of the stack region).

Defined as the stack limit value from the linker script.

◆ STACK_FILL_WORD

#define STACK_FILL_WORD   0xA5A5A5A5U

32-bit fill pattern written to the stack region.

Used to initialize the stack and detect high-water mark.

◆ STACK_GUARD_WORD

#define STACK_GUARD_WORD   0xDEADBEEFU

Guard word placed at STACK_LIMIT to detect overflow.

This value is checked to detect stack overflows.

◆ STACK_MONITORING_SAVE_SCAN_PTR

#define STACK_MONITORING_SAVE_SCAN_PTR   0

Enable saving a scan pointer between updates.

When enabled, svc_stack_mon_update uses the previous scan position (with an optional back-step via STACK_SCAN_SKIP ) to reduce scan time.

Note
The scan still assumes that used stack forms a contiguous region near STACK_TOP.
