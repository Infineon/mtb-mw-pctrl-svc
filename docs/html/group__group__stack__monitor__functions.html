◆ svc_stack_mon_init()

void svc_stack_mon_init ( void )

Initialize the stack monitor.

Writes STACK_GUARD_WORD at STACK_LIMIT and fills the range [STACK_LIMIT + 1, STACK_TOP) with STACK_FILL_WORD. This should be called once early at boot.

Warning
Calling this after the stack has already been used will overwrite stack memory.

◆ svc_stack_mon_update()

size_t svc_stack_mon_update ( void )

Update and return the stack high-water mark.

Scans the stack region for the first word that differs from STACK_FILL_WORD and updates the internally stored high-water mark.

Returns
Highest observed stack usage (high-water) in bytes.
Note
This estimate may under-report stack usage if reserved stack space is never written.
