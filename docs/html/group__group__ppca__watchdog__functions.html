uint32_t core1_protection_time,

Initialize ppca watchdog timer.

Parameters
core0_protection_timeProtection time for core0 in us. Set to 0 to disable.
core1_protection_timeProtection time for core1 in us. Set to 0 to disable.
core0_wdt_modeWatchdog mode for core0.
core1_wdt_modeWatchdog mode for core1.
core0_cbCallback executed on Core0 WDT interrupt. Can be NULL.
core1_cbCallback executed on Core1 WDT interrupt. Can be NULL.
Note
This function should be called from main core only.
In INT_RESET mode, the handler clears the interrupt for the first two occurrences and allows reset on the third.

◆ ppca_wdt_handler()

void ppca_wdt_handler ( void )

PPCA watchdog timer interrupt handler.

Note
In INT_RESET mode, the interrupt is cleared for the first two occurrences only. The third occurrence is left uncleared so the hardware can reset the device.
This function should be called from main core only.
