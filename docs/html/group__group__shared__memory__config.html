Shared Memory

General Description

The configuration is defined in cy_ppca_shm_config.h.

Copy that template file to the shared/ folder of your multi-core application, remove the #warning line, and adjust the CONFIG_* defines to match your needs. Add the folder to every core project Makefile with SEARCH += ./../shared so the project-specific copy is picked up instead of the library template.

Configuration option to enable or disable the use of IPC lock for shared memory block access.

Note

Configuration option to enable or disable the use of mutex lock for shared memory block access.

Note
Only one of CONFIG_USE_IPC_LOCK or CONFIG_USE_MUTEX_LOCK should be enabled.

◆ CONFIG_USE_LOCK_MAX_CHAL_NUM

#define CONFIG_USE_LOCK_MAX_CHAL_NUM   4

CONFIG - Base lock number.

Configuration option to set the base lock number for shared memory block access. For IPC Lock, this is the base IPC channel number used for locking. For Mutex Lock, this is the base mutex index.

CONFIG - Max number of locks

Configuration option to set the maximum number of locks for shared memory block access.
