◆ mutex_lock()

static bool mutex_lock ( volatile mutex_t * mutex)
inlinestatic

Locks the mutex.

This function attempts to lock the mutex. If the mutex is already locked, it will return false. If the mutex is successfully locked, it will return true.

Parameters
mutexPointer to the mutex variable. For multi-core systems, the mutex variable must be in shared memory.
Returns
true if the mutex was successfully locked.
false if the mutex was already locked.
Note
assembly code mutex_lock: ldrex r3, [r0] cbnz r3, .L2 movs r3, #1 strex r2, r3, [r0] cbnz r2, .L4 dmb 0xF mov r0, r3 bx lr .L2: clrex bx lr .L4: bx lr
